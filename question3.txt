Question Title: Data Breach Response.

Question Link:
https://my.newtonschool.co/playground/code/orlr84xpc3oo?lecture_hash=vifkrugjcwth

Solution:

cd breach_response
cp evidence/log_dump.txt /box/breach_response
chmod 777 /box/breach_response/evidence
mv evidence secure
chmod 555 /box/breach_response/secure/evidence
chmod 777 /box/breach_response/reports/incident_summary.txt
echo "Breach confirmed" >> /box/breach_response/reports/incident_summary.txt
chmod 444 /box/breach_response/reports/incident_summary.txt
cd secure
echo "Forensics Complete" >> forensics_report.txt
chmod 600 forensics_report.txt
cd ..
chmod 777 /box/breach_response/reports/incident_summary.txt
echo "Escalated to security team" >> /box/breach_response/reports/incident_summary.txt
chmod 444 /box/breach_response/reports/incident_summary.txt

Approach:

1. Use cd breach_response to enter the breach response directory.
2. Use cp to copy log_dump.txt to /box/breach_response.
3. Use chmod 777 to grant full permissions to the evidence directory.
4. Use mv evidence secure to move the evidence directory to secure.
5. Use chmod 555 to give read and execute permissions to the renamed evidence directory.
6. Use chmod 777 to grant full permissions to incident_summary.txt.
7. Append "Breach confirmed" to the incident summary using echo and >>.
8. Use chmod 444 to make the incident summary read-only.
9. Use cd secure to enter the secure directory.
10. Append "Forensics Complete" to forensics_report.txt.
11. Use chmod 600 to give read and write permissions only to the file owner.
12. Use cd .. to return to the parent directory.
13. Temporarily grant full permissions to incident_summary.txt using chmod 777.
14. Append "Escalated to security team" to the incident summary.
15. Use chmod 444 to restore read-only permissions to the incident summary.
